Designing and deploying under a budget
Start from embedded textIt is cheap, and often reliable on born-digital documents.
Add the page imageWhen the task needs appearance, or the text looks unreliable.
Re-parse only if neededWhen the existing text is inadequate, such as on scans.

Richer input costs time and memory on every page, so choose the modality and the number of pages together.
