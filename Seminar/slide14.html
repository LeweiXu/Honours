SimpleDoc. Stage 1 indexes each page as an embedding and a summary. Stage 2 retrieves and re-ranks pages, and a reasoning agent answers or updates its memory and query. From Jain et al., EMNLP 2025.
How it works
  • Pre-processing. Every page is indexed twice: as a visual embedding, and as a short summary written by a vision-language model.
  • Dual-cue retrieval. Pages are shortlisted by embedding similarity, then a language model re-ranks them using the summaries.
  • Reasoning agent. It reads the retrieved pages with a working memory of earlier notes, then either answers or issues a refined query to retrieve more.
  • The loop ends when it answers, decides the question is not answerable, or reaches a step limit.
