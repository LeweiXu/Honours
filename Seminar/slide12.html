Agentic Methods

The current frontier. A controller selects each evidence-gathering action at inference time rather than executing a plan fixed in advance, so compute scales with question difficulty rather than document length, and the action sequence becomes an inspectable audit trail.

Inference-time

ReAct and tool use. Thought and action interleave in one stream, each observation feeding the next step. Actions are either document-side tool calls to retrievers, parsers, and OCR engines, or structured navigation over a pre-built representation, which trades dependence on tool fidelity for dependence on the index.

Agentic decomposition. Split the workflow across controllers, each on a narrower input than one backbone doing everything. Modality-specialised variants read text and vision separately and reconcile; role-specialised variants assign plan, execute, verify, and answer, with routing back when a stage detects an error.

Trained

Trajectory distillation. Clone a stronger teacher's trajectories by supervised fine-tuning on think-action-observation turns, with rollouts collected in closed-loop interaction and filtered for format validity, answer correctness, and evidence coverage.

Reinforcement-learned. Optimise the policy directly against trajectory-level rewards combining answer correctness, evidence recall, and tool-use shape, over a constrained action space. Learned termination is a recurring concern, with entropy-based stopping letting the model commit once confidence stabilises.

The price of that flexibility: inference cost is hard to bound in advance, controllers are prompt-sensitive and can commit early to the wrong evidence, and the system still inherits the recall ceiling of every tool it consults.
