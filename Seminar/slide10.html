Retrieval and Navigation

Retrieval narrows a long document to compact evidence units. Two families have emerged, distinguished by whether passages are scored independently against the query or navigated through document structure.

Inference-time

Similarity-based. Score each passage against the query independently and return the top-ranked subset. Dense retrieval has consolidated around late-interaction encoders such as ColPali, which align query tokens to page patches by MaxSim; BM25 persists as a sparse baseline, and a second LLM reranking stage commonly refines the recall.

Relation-aware. Retrieve along explicit structure instead. Tree variants group passages under recovered section headings so retrieved chunks keep their parent context; graph variants make headings, entities, and cross-references nodes with typed edges, so a controller can traverse to related passages rather than rely on similarity.

Trained

Modality alignment. Learn visual page embeddings that stay aligned with OCR-derived text, so page images can be retrieved without late interaction's storage and latency cost.

Cross-page fusion. Enrich each page representation with neighbouring-page context through a lightweight LoRA head, making evidence spread across adjacent pages retrievable as one unit.

Logical relevance. Train graph scorers to rank pages by their role in cross-page reasoning paths, turning retrieval into a learned multi-hop walk rather than a single similarity match.

Independent scoring handles paraphrase and cross-modal queries well, but cannot follow a reference or a multi-hop dependency that no single passage carries.
