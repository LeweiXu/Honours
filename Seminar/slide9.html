Text Modality

Text is the cheap modality: we can search it and read it efficiently. The problem is that a long document contains far too much of it.

  • Volume. A system either compresses every page into a fixed budget, or selects only the passages it thinks it needs. Both are lossy, and either can discard the thing that turns out to matter.
  • Continuity. Paragraphs, tables, and section context run across page boundaries, so a chunk cut at the wrong place loses the context that makes it readable.
  • Noise. OCR and parsing errors accumulate across pages. Because extracted text is usually also the retrieval index, those errors degrade finding as well as reading.
  • Heterogeneity. Text density varies sharply from page to page, yet almost every system applies one fixed budget to the whole document.

Some evidence cannot be recovered from text at all. That is where the page image matters.
