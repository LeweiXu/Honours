% Accuracy (\%) on oracle pages, Qwen3-VL-8B bf16, PaddleOCR-VL, full answerable pool ($n=847$). Teal deepens with accuracy on a fixed scale, and bold marks each row's winning rung within the med-resolution ladder. The \textbf{Ladder @ med} block is the four rungs at medium resolution: text alone (T), parser layout (TL), parser layout with the page image (TLV), and the image alone (V). The \textbf{TLV} and \textbf{V} blocks give those two rungs at low and high resolution; the medium value for each is the corresponding Ladder column. The \textbf{$\Delta$V} column ($\Delta$V = TLV$-$V at med) is a point difference, not an accuracy, so it carries its own warm shading, deepening with the accuracy the text channel recovers over vision alone. Domain rows partition the pool; evidence-source rows overlap, since a question citing several sources appears under each, so their counts do not sum and the \textbf{All} row pools each question once. Resolution lifts the pixel-limited sources most: on V, Table climbs $25.3\rightarrow42.4$ and Chart $34.3\rightarrow48.3$ from low to high, while Pure-text moves little.\par}
