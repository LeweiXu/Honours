% Pool: the answerable set on oracle pages, n=847 paired questions per cell (every
% question scored under both prompt modes at that rung). Only the instruction changes
% between the two sides, so every flip is the instruction's.
% R→W splits into the two ways a correct answer is lost: the model refuses a question
% it had answered correctly (false abstention), or it still answers and answers wrongly.
% The two split rows sum to the R→W row; R→W minus W→R is the Net row, which reproduces
% the accuracy change between the same two prompt modes in Table~\ref{tab:prompting_full}
% (the abstentions row of that table's false-abstention block is reproduced exactly by the
% builder's `abstentions` column, which is the check that the two tables share a pool).
% HEAT: warm on the three loss rows, one shared scale [0,15] so a component reads against
%   its total; green on W→R [0,4]. Macro names are unique to this table (\aRW/\aWR).
